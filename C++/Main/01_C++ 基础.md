
## 语法和程序结构

```cpp
#include <iostream>

int main()
{
   std::cout << "Hello world!";
   return 0;
}
```

`include <iostream>`：预处理器 希望使用`iostream`的库（不然无法使用`std::cout` ）

## 注释

`//`：单行注释
```cpp
std:cout << "Hello world!\n"; //
cout lives in the iostream library
```
`/*` `*/`：多行注释

## 对象和变量简介

数字：`-6.7`
字符：`'H'` 使用单引号
文本：`Hello World!` 使用双引号

**定义**
```cpp
int x;

int a,b;

double c;
```

## 变量赋值和初始化

```cpp
int width;

width = 5;

int b = 5;

int c ( 6 );

int d { 7 };

int e {};

// 推荐使用列表初始化值或值初始化即 {}/()
```

```cpp
//告诉编译器不介意变量未使用 避免警告（一般不会影响编译）
[[maybe_unused]] double pi { 3.14 };
```

## iostream 简介：cout、cin和、endl

cout：字符输出
endl：输出换行符（`'\n'`）
cin：字符输入

cout 和 cin 均是缓冲的

## 未初始化变量和未定义行为

**未初始化变量：** 程序未给其赋值（通常通过初始化或赋值）的变量

务必避免所有导致未定义行为都情况，例如使用未初始化变量

## 关键词和命名标识符

**标识符：**
- 非关键词
- 字母、数字、下划线组成
- 不能以数字开头
- 区分大小写

单个单词：小写字母
用户定义的类型：大写开头
多词变量/函数名：驼峰命名
