## 1 半导体基础器件（上）

半导体：本征半导体、杂质半导体
杂质半导体：
N型半导体：五价（P），自由电子多，空穴少（电子半导体）
P型半导体：三价（B），空穴多，自由电子少（空穴半导体）

采用不同的掺杂工艺，通过扩散作用，将 N 型半导体与 P 型半导体制作在同一块硅片上，在它们的交界面就形成了 **PN 结**，具有单向导电性

**二极管**
单向导电性；伏安特性

| 材料               | 硅 ($Si$)        | 锗 ($Ge$)        |
| :--------------- | :-------------- | :-------------- |
| 开启电压 $U_{on}$    | $0.5V$          | $0.1V$          |
| 导通电压 $U_{D(on)}$ | $0.6 \sim 0.8V$ | $0.1 \sim 0.3V$ |
| 反向饱和电流 $I_s$     | $nA$ 级          | $\mu A$ 级       |

**基本运算法则：**
- $0 \cdot A = 0$
- $1 \cdot A = A$
- $A \cdot A = A$
- $A \cdot \bar{A} = 0$
- $0 + A = A$
- $1 + A = 1$
- $A + A = A$
- $A + \bar{A} = 1$
- $\bar{\bar{A}} = A$

**交换律：**
- $AB = BA$
- $A + B = B + A$

**结合律：**
- $ABC = (AB)C = A(BC)$
- $A + B + C = A + (B + C) = (A + B) + C$

**分配律：**
- $A(B + C) = AB + AC$
- $A + BC = (A + B)(A + C)$

**吸收律：**
- $A(A + B) = A$
- $A(\bar{A} + B) = AB$
- $A + AB = A$
- $A + \bar{A}B = A + B$
- $AB + A\bar{B} = A$
- $(A + B)(A + \bar{B}) = A$

**反演律（摩根定律）：**
- $\overline{AB} = \bar{A} + \bar{B}$
- $\overline{A + B} = \bar{A} \cdot \bar{B}$

2. 画出表示该逻辑函数的卡诺图
3. 选取可合并的最小项
