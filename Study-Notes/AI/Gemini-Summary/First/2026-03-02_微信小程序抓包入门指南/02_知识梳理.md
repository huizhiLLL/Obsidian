# 微信小程序抓包入门指南 - 知识梳理

## 涉及的技术栈/工具

- **Fiddler Classic** - Windows 抓包工具（免费）
- **Charles** - 跨平台抓包工具（界面友好）
- **Burp Suite** - 安全测试工具
- **Stream** - iOS 抓包软件
- **HttpCanary** - 安卓抓包工具（已停更）
- **Packet Capture** - 安卓端抓包
- **MitM Proxy** - 中间人代理原理

## 关键概念与方法

- **抓包原理**: 代理服务器充当中间人，转发请求和响应
- **HTTPS 解密**: 需要安装根证书才能查看加密流量
- **接口识别**: 寻找 GET 方法、URL 参数清晰、返回标准 JSON 的接口

- **难度分级**:
  - PC 端微信: ★ 简单（新手首选）
  - iOS: ★★ 中等
  - Android 7.0 以下: ★★ 中等
  - Android 7.0 及以上: ★★★★★ 极难（需要 Root + Magisk）

- **简化场景策略**:
  - Level 1: 裸奔测试（直接访问）
  - Level 2: 伪装 Header（User-Agent、Referer）
  - Level 3: Token 身份验证

## 重要的代码片段或命令

```bash
# Fiddler 配置步骤
1. 下载安装 Fiddler Classic
2. Tools -> Options -> HTTPS -> 勾选 Decrypt HTTPS traffic
3. 信任 Fiddler Root 证书
4. 在手机/模拟器设置代理为电脑 IP:8888
5. 访问 http://电脑IP:8888 下载证书
6. 信任证书后开始抓包
```

## 可复用的经验/最佳实践

1. **从 PC 端开始**: Windows/Mac 微信抓包难度最低，成功率最高
2. **优先找"软柿子"接口**: 不需要复杂验证的 GET 接口最容易获取
3. **理解业务逻辑**: 看懂接口的参数和返回值含义比单纯抓包更重要
4. **分层挑战**: 先从简单接口开始，逐步尝试需要认证的接口
5. **合法使用**: 抓包仅限于技术研究和个人学习，勿用于恶意用途
6. **工具选择**: Fiddler 免费且功能足够，入门首选
