# 魔方计时器年度报告数据分析工具 - 知识梳理

## 涉及的技术栈/工具

- **SQLite** - dctimer 数据库格式
- **DB Browser for SQLite** - 数据库可视化工具
- **Python sqlite3 + pandas** - 数据解析处理
- **ECharts** - 数据可视化库（Vue 3）
- **Vue 3** - 前端框架

## 关键概念与方法

- **数据清洗**: 处理 DNF（未完成）、+2（罚时）、Unix 时间戳转换
- **数据统计**: 分组统计、滚动平均计算
- **用户画像标签**: 基于数据生成趣味标签（深夜党、PB 机器等）
- **Niche Market 产品**: 垂直细分市场需求

- **核心功能维度**:
  - 总量统计: 全年复原次数、总时长（换算天数）
  - 高光时刻: 刷新 PB 次数、各项最佳成绩
  - 习惯分析: 活跃时段分析（深夜党 vs 晨练党）
  - 趣味标签: 无情 DNF 机器、手速狂魔等

## 重要的代码片段或命令

```python
# SQLite 数据读取示例
import sqlite3
import pandas as pd

conn = sqlite3.connect('dctimer.db')
df = pd.read_sql_query("SELECT * FROM sessions", conn)

# 数据清洗
df['time'] = df['time'].apply(lambda x: None if x < 0 else x)  # DNF 处理
df['timestamp'] = pd.to_datetime(df['unixtime'], unit='s')     # 时间戳转换

# 按月份统计
monthly_stats = df.groupby(df['timestamp'].dt.month).agg({
    'time': ['count', 'mean']
})
```
