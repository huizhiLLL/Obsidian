# Linux WSL2 - 知识梳理

## 涉及的技术栈/工具

- **虚拟化技术**：WSL2 (Windows Subsystem for Linux)
- **发行版**：Ubuntu 22.04 LTS
- **容器引擎**：Docker Desktop
- **终端美化**：Zsh + Powerlevel10k
- **服务部署**：DeepLX翻译服务、Komari Agent探针
- **云服务**：AWS EC2

## 关键概念与方法

- **WSL安装问题处理**：解决0x80071772文件系统错误，取消文件夹压缩
- **Docker配置**：WSL2与Docker Desktop集成
- **国内网络加速**：使用ghproxy镜像解决GitHub下载慢
- **Systemd服务管理**：手动创建systemd服务文件（非自动脚本）
- **终端美化配置**：Zsh、Powerlevel10k主题、字体配置
- **SSH远程连接**：配置SSH密钥连接云服务器

## 重要的代码片段或命令

```bash
# WSL安装（管理员PowerShell）
wsl --install
wsl --set-default-version 2

# Docker服务启动
sudo systemctl start docker
sudo systemctl enable docker

# DeepLX部署
wget https://github.com/XDXF/docker-deepLX/archive/refs/heads/main.tar.gz
# 或使用ghproxy镜像
wget https://ghproxy.com/https://github.com/XDXF/docker-deepLX/archive/refs/heads/main.tar.gz

# Zsh安装
sudo apt install zsh
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
git clone --depth=1 https://github.com/romkatv/powerlevel10k.git $ZSH_CUSTOM/themes/powerlevel10k
```

```ini
# systemd服务文件示例 (/etc/systemd/system/komaribot.service)
[Unit]
Description=Komari Bot Service
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/komari
ExecStart=/usr/bin/python3 main.py
Restart=always

[Install]
WantedBy=multi-user.target
```

## 可复用的经验/最佳实践

1. **国内服务器网络加速**：使用ghproxy镜像或本地下载+scp上传
2. **Systemd服务手动创建**：不要依赖自动脚本，要理解服务配置
3. **终端美化提升效率**：Zsh + Powerlevel10k提供更好的开发体验
4. **WSL2文件系统注意**：取消Windows文件夹压缩避免安装错误
5. **SSH密钥管理**：使用密钥而非密码登录服务器
