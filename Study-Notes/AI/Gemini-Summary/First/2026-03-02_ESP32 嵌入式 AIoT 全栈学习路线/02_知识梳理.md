# ESP32 嵌入式 AIoT 全栈学习路线 - 知识梳理

## 涉及的技术栈/工具

- **开发板**：ESP32 系列
- **开发环境**：PlatformIO（核心推荐，超越Arduino IDE）
- **通信协议**：MQTT（物联网通信）、WebSocket（Web实时通信）
- **总线协议**：I2C、SPI、UART（传感器与模块通信）
- **硬件控制**：GPIO、PWM、舵机控制、步进电机、 PID控制

## 关键概念与方法

- **PlatformIO vs Arduino IDE**：PlatformIO提供更专业的项目管理、依赖管理和跨平台支持
- **MQTT vs WebSocket**：MQTT适合设备间通信（发布/订阅模式），WebSocket适合Web端实时交互
- **嵌入式开发思维**：实时循环（while True）而非事件驱动，物理世界没有Ctrl+Z
- **学习阶段划分**：
  - 第一阶段：点灯与GPIO（2-3天）
  - 第二阶段：总线协议与传感器（3-5天）
  - 第三阶段：联网与全栈联动（5-7天）—— 重点是MQTT协议
  - 第四阶段：机电控制（舵机、步进电机、PID）

## 重要的代码片段或命令

```cpp
// PlatformIO 项目结构示例
#include <Arduino.h>

void setup() {
    pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
    digitalWrite(LED_BUILTIN, HIGH);
    delay(1000);
    digitalWrite(LED_BUILTIN, LOW);
    delay(1000);
}
```

## 可复用的经验/最佳实践

1. **放弃Arduino IDE，使用PlatformIO**：更专业的嵌入式开发环境
2. **限位保护是嵌入式开发的第一要务**：物理世界没有Ctrl+Z
3. **MQTT是物联网的核心协议**：设备端通信的首选
4. **Web技能与硬件结合**：WebSocket用于Web端展示，MQTT用于设备控制
5. **实时循环思维**：区别于Web的事件驱动模型
