# 机械软件交叉文献综述建议 - 知识梳理

## 涉及的技术栈/工具

- **数字孪生 (Digital Twin)** - 物理设备的虚拟映射
- **Web 可视化技术** - Vue / React / Three.js
- **Google Scholar** - 学术论文搜索
- **PLC / 传感器** - 工业数据采集

## 关键概念与方法

- **文献综述本质**: "绘制知识地图"而非记流水账
- **重构知识**: 像重构代码一样组织和呈现文献
- **交叉学科选题**: 结合机械（硬件）与软件（Web 开发）的数字孪生方向

- **数字孪生架构**:
  - 物理层: 机械设备 + 传感器/PLC
  - 传输层: 后端 API (Node.js/Flask)
  - 展示层: 前端可视化 (Vue/React/Three.js)

## 可复用的经验/最佳实践

1. **选题策略**: 选择能发挥软件优势的方向，如 Web 可视化
2. **文献组织**: 按主题而非年份组织，形成清晰的知识结构
3. **降维打击**: 用熟悉的软件知识处理陌生领域
4. **倒三角结构**: Introduction 吸引注意，Body 详细展开，Conclusion 简洁有力
5. **技术架构图**: 用架构图替代大量文字，PPT 和论文都适用
6. **Google Scholar 技巧**: 利用筛选功能找到近3-5年的高质量论文
