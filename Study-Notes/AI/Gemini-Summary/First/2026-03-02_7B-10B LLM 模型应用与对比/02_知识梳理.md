# 7B-10B LLM 模型应用与对比 - 知识梳理

## 涉及的技术栈/工具

- **本地部署工具**：Ollama、Chatbox
- **模型选择**：DeepSeek-R1-Distill-Qwen-1.5B、Qwen2.5-0.5B
- **应用场景**：RAG终端、代码补全、数据清洗、垂直专家模型
- **硬件要求**：消费级GPU（8GB+ VRAM）或Apple Silicon

## 关键概念与方法

- **7B模型定位**："黄金尺寸"，消费级硬件与实用智能的平衡点
- **模型能力对比**：
  - 7B = "实习生"：适合特定任务，简单推理
  - 旗舰模型 = "教授"：复杂推理，世界知识丰富
- **部署门槛**：7B模型可在消费级硬件上运行，旗舰模型需要高端GPU
- **SLM（Small Language Model）**：0.5B-3B参数的模型，适合低资源场景

## 重要的代码片段或命令

```bash
# 使用Ollama运行本地模型
ollama run deepseek-r1:1.5b

# 查看可用模型
ollama list
```

## 可复用的经验/最佳实践

1. **7B是"黄金尺寸"**：在消费级硬件与实用智能之间取得最佳平衡
2. **小模型适合特定任务**：不适合复杂推理，但适合RAG、代码补全等垂直场景
3. **本地部署玩一玩**：Ollama + Chatbox是最佳入门组合
4. **模型参数量的能力边界**：世界知识弱、推理能力有限，但部署门槛低
5. **从1.5B开始**：DeepSeek-R1-Distill-Qwen-1.5B是推荐的入门模型
