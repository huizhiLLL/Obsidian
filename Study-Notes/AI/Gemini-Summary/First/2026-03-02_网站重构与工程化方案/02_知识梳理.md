# 网站重构与工程化方案 - 知识梳理

## 涉及的技术栈/工具

- **NestJS** - Node.js 后端框架（模块化、TypeScript）
- **PostgreSQL** - 关系型数据库
- **Prisma ORM** - 数据库 ORM 工具
- **Vue 3** - 前端框架
- **Tailwind CSS** - Utility-first CSS 框架
- **Naive UI** - Vue 3 组件库
- **Docker Compose** - 容器编排
- **1Panel** - 服务器管理面板
- **GitHub Actions** - CI/CD 持续集成

## 关键概念与方法

- **工程化转型**: 从"脚本式"到"工程级"的架构升级
- **模块化分层**: NestJS 强制模块化，TypeScript 类型安全
- **数据库迁移**: MongoDB -> PostgreSQL，利用 JSONB 保留灵活性
- **Redis Pub/Sub**: 与 AstrBot 解耦通信
- **定时任务**: NestJS 内置 Cron 模块

## 可复用的经验/最佳实践

1. **Vibe Coding vs 工程化**: 灵感爆发靠 vibe coding，长久维护靠工程化
2. **技术选型原则**: NestJS + PostgreSQL + Vue3 + Tailwind 是成熟组合
3. **JSONB 替代 MongoDB**: PostgreSQL 的 JSONB 可以处理灵活字段
4. **VPS 优于 Serverless**: 对于长期项目，VPS 成本可控且灵活性更高
5. **Docker Compose 编排**: 简化多服务部署和运维
6. **CI/CD 自动化**: GitHub Actions 实现自动化部署
7. **模块化思维**: 目录结构清晰是工程化的基础
