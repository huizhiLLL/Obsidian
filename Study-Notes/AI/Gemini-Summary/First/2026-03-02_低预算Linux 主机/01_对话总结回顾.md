## 对话背景与目标

用户是一名大学生、计算机爱好者，拥有 Windows 笔记本用于日常使用。希望在本地搭建一台独立的 Linux 主机用于学习，需求性能不高，最多运行一些脚本（如 AstrBot 部署）。预算控制在几百元之内，希望获得可行的硬件配置方案。

## 核心问题与需求

1. **硬件选型**：在预算有限的情况下，如何组装一台能够运行 Linux 的主机？
2. **校园网适配**：用户的学校使用校园网，没有路由器，如何解决网络连接问题？
3. **系统安装**：拿到机器后应该安装什么操作系统？如何进行无显示器远程管理？
4. **后续部署**：如何在此机器上配置 Docker 环境并部署 AstrBot？

## 解决过程

对话分为硬件选购和校园网解决方案两个主要部分：

1. **硬件选购方案**：
   - 方案一（推荐）：1L 迷你商用机（联想 ThinkCentre M73/M93p、HP ProDesk 400/600 G1/G2 DM），预算约 300-450 元，x86 架构兼容性好，做工优秀
   - 方案二：斐讯 N1 盒子（ARM 架构），预算约 80-100 元，极致省钱但需要折腾刷机
   - 方案三：J1900/N3450 工控机，介于两者之间

2. **校园网网络方案**：
   - 核心方案：Windows 网络共享（ICS）。用户笔记本连接校园网 Wi-Fi，通过网线直连 Linux 主机，Windows 作为网关分享网络
   - 详细步骤：物理连接、ICS 配置、Linux 设置为 DHCP、SSH 连接方法
   - 备选方案：命令行浏览器认证（w3m/lynx）

3. **系统安装建议**：推荐 Ubuntu Server 22.04 LTS 或 Debian 12，无 GUI，锻炼 CLI 能力。开发方式采用 VS Code + Remote SSH，与云服务器体验一致。

## 最终结果与结论

用户获得了完整的低预算 Linux 主机构建方案。明确了购买清单（准系统、内存、硬盘、总计约 340 元）和系统安装建议。针对校园网的特殊限制，获得了通过 Windows 网络共享的解决方案。同时理解了无显示器环境下的远程管理方法。

## 反思与延伸

对于大学生来说，拥有一台独立的 Linux 物理机是理解操作系统原理、网络协议和容器化部署的最佳实践。相比云服务器，本地物理机的学习成本更低、试错空间更大。这台机器不仅可以用于学习，还能在未来的项目中持续发挥作用。
