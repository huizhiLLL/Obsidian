### 核心心法：将物品属性映射为计算机概念
现实物品分类困难，是因为你试图用“名字”分类，而不是用“调用频率”和“功能模块”分类。

1. **桌面 (Desktop) = L1 Cache / RAM**
  - **定义**：极高频访问区。
  - **约束**：必须保持低延迟。任何一周用不到一次的东西，都不允许出现在这里。
  - **对象**：键盘、鼠标、正在喝的水、当日必须处理的“任务栈”（纸质书/笔记）。
2. **第一层抽屉 = L2 Cache**
  - **定义**：高频工具区。触手可及，无需起身。
  - **对象**：CS 领域的 USB Hub、常用线缆（Type-C/Lightning）、机械领域的卡尺、螺丝刀、常用文具。
3. **下层抽屉/收纳盒 = HDD / Cold Storage**
  - **定义**：低频归档区。
  - **对象**：囤积的卫生纸、备用线缆、包装盒（建议直接 Garbage Collection）、非当季衣物。

### 具体执行方案：宿舍书桌重构 (Refactoring)

#### 1. 引入“容器化” (Containerization) —— 解决无序
现实物品没有扩展名，所以你需要给它们强行套上容器。

- **推荐方案：Gridfinity (强烈推荐)**
  - 鉴于你是**机械工程专业**，你绝对会爱上这个系统。
  - **概念**：由 Zack Freedman 开发的开源模块化收纳系统。基于 42mm 网格，万物皆可模块化。
  - **操作**：你可以用学校的 3D 打印机打印底座（Baseplate）和收纳盒（Bins）。
  - **效果**：螺丝、SD 卡、转接头、魔方润滑油，每个都有固定的“Slot”。这就像给每个物品分配了固定的内存地址。
  - **替代**：如果不想打印，去买“分隔收纳盒 (Drawer Dividers)”，把抽屉切分成网格。**不要让抽屉成为一个大 blob，要把它变成 array。**

#### 2. 建立索引 (Indexing) —— 解决查找慢

- **硬件**：搞一个 **标签打印机 (Label Printer)**（比如精臣 B21 之类）。
- **逻辑**：
  - **线缆**：不要扔在那一团乱。每一根线两端贴标签：`Power: 100W`、`Data: USB 3.0`。
  - **盒子**：不透明的盒子必须贴标签，标明内容物。这是你的 `ls -l`。

#### 3. 总线管理 (Bus Management) —— 解决线缆杂乱
宿舍书桌最容易乱的就是线。

- **原则**：线缆必须“走线槽”，严禁“飞线”。
- **工具**：
  - **魔术贴扎带 (Velcro Ties)**：代替扎带（Zip Ties），方便复用和重构。
  - **桌下理线架 (Under-desk Cable Tray)**：把插排（Power Strip）和电源适配器（Adapter）全部扔到桌子下面去。桌面上只留接口。
  - **分流**：将强电（220V）和弱电（网线/信号线）尽量分开，虽然在宿舍里干扰不大，但这是极客的自我修养。

### 针对你当前情况的 Quick Start 算法
如果你现在坐在桌前不知所措，请执行以下 `init.sh` 脚本：

1. **Garbage Collection (GC):**
  - 把桌面上**所有**东西全部扫到床上（临时 Heap）。
  - 用抹布擦干净桌子（Format Disk）。
2. **Dependency Check (依赖检查):**
  - 从床上一个一个拿东西，问自己：
    - “这周我会用它超过 3 次吗？” -> **Yes**: 放回桌面固定位置 (Pinned)。
    - “这是必须伸手就能拿到的吗？” -> **Yes**: 放进第一层抽屉 (L1 Cache)。
    - “我不知道这是啥/可能以后有用？” -> **No**: 扔进底层抽屉或收纳箱 (Archive)。
    - “这是垃圾吗？” -> **Yes**: `rm -rf` (垃圾桶)。
3. **Modularization (模块化分类):**
  - **电子类 (Electronics)**: 各种线、充电头、转接器 -> **统一收纳盒 A**。
  - **魔方/机械 (Hobby)**: 螺丝刀、润滑油、魔方本体 -> **统一收纳盒 B**。
  - **生活/文具 (Life)**: 指甲刀、笔、药 -> **统一收纳盒 C**。
  - *Debug*: 如果发现某个类别太杂（比如“电子类”里既有 3.5mm 线又有 HDMI），就继续拆分 (Sub-classing)。
