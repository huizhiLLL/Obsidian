# MCP：AI Agent 的新标准 - 知识梳理

## 涉及的技术栈/工具

- **协议标准**：MCP (Model Context Protocol)
- **核心能力**：Resources（读取资源）、Tools（使用工具）、Prompts（获取提示）
- **项目应用**：AstrBot、HZCubing网站
- **实现技术**：SSE、Stdio连接方式
- **辅助工具**：Python + Flet + Napcat（快捷键呼出聊天）

## 关键概念与方法

- **MCP定位**："AI时代的USB-C接口"，统一AI与外部系统的通信标准
- **三大核心能力**：
  - Resources：AI可以读取的文件、数据库等资源
  - Tools：AI可以调用的函数或服务
  - Prompts：预设的提示模板
- **传统插件 vs MCP模式**：
  - 插件模式：触发式，由人主动触发
  - MCP模式：决策式，AI自主决策调用
- **Agent Skills**：动态工具检索机制
  - 技能库注册
  - 语义检索
  - 动态加载
- **MCP + RAG组合**：知识检索 + 工具调用

```python
# 简单MCP Server示例
from mcp.server import Server
from mcp.types import Tool

app = Server("example-server")

@app.list_tools()
async def list_tools() -> list[Tool]:
    return [
        Tool(
            name="run_command",
            description="Run a Linux command",
            inputSchema={"type": "object", "properties": {"cmd": {"type": "string"}}}
        )
    ]

@app.call_tool()
async def call_tool(name: str, arguments: dict) -> str:
    if name == "run_command":
        import subprocess
        result = subprocess.run(arguments["cmd"], shell=True, capture_output=True, text=True)
        return result.stdout
    return ""
```
