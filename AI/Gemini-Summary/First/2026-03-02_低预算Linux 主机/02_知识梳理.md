# 低预算Linux 主机 - 知识梳理

## 涉及的技术栈/工具

- **硬件方案**：
  - 1L迷你商用机（ThinkCentre M73/M93p、HP ProDesk 400/600）
  - 斐讯N1盒子（ARM架构）
  - J1900/N3450工控机
- **操作系统**：Ubuntu Server 22.04 LTS、Debian 12
- **开发工具**：VS Code + Remote SSH
- **网络共享**：Windows ICS（Internet Connection Sharing）

## 关键概念与方法

- **硬件选购方案**：
  - 方案一（推荐）：1L迷你商用机，预算300-450元，x86架构兼容性好
  - 方案二：斐讯N1盒子，预算80-100元，极致省钱但需刷机
  - 方案三：J1900/N3450工控机，介于两者之间
- **校园网解决方案**：Windows网络共享（ICS）
  - 笔记本连接校园网Wi-Fi
  - 通过网线直连Linux主机
  - Windows作为网关分享网络
- **无显示器远程管理**：SSH连接

## 重要的代码片段或命令

```bash
# Windows端配置ICS（管理员PowerShell）
# 1. 查看网络适配器
Get-NetAdapter

# 2. 启用ICS
netsh routing ipnat install
# 或使用图形界面：控制面板 -> 网络和共享中心 -> 更改适配器设置 -> 属性 -> 共享
```

```bash
# Linux端配置
# 设置为DHCP自动获取IP
sudo vim /etc/netplan/00-installer-config.yaml

# 网络配置示例
network:
  ethernets:
    eth0:
      dhcp4: true
  version: 2

# 应用配置
sudo netplan apply
```

```bash
# SSH连接
ssh user@192.168.137.x  # Windows ICS分配的IP
```

## 可复用的经验/最佳实践

1. **1L迷你机是最佳选择**：做工优秀，兼容性好，价格适中
2. **校园网 ICS 方案**：无需路由器，利用现有设备
3. **无GUI的Server版本**：锻炼CLI能力，与云服务器体验一致
4. **VS Code Remote SSH**：开发体验与云服务器一致
5. **本地物理机学习价值高**：理解操作系统原理、网络协议和容器化部署
