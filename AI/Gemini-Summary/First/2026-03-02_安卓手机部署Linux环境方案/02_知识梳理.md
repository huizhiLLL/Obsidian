# 安卓手机部署Linux环境方案 - 知识梳理

## 涉及的技术栈/工具

- **终端模拟器**：Termux
- **Linux发行版**：PRoot-Distro、Andronix、AnLinux、AidLux、UserLAnd、PostmarketOS
- **架构**：ARM64（arm64-v8a）
- **包管理**：apt、yum等（取决于安装的发行版）

## 关键概念与方法

- **Termux**：安卓终端模拟器，无需Root
- **PRoot-Distro**：Termux官方插件，运行完整Linux发行版
- **Andronix & AnLinux**：辅助App，一键安装带GUI的Linux
- **AidLux**：国产方案，Web桌面环境，对AI框架有优化
- **UserLAnd**：独立App，最简单的完整发行版体验
- **PostmarketOS**：终极方案，需要刷机
- **幻影进程杀手**：安卓后台管理机制，需要加入白名单
- **Debug版vs正式版**：F-Droid版本更适合长期使用

## 重要的代码片段或命令

```bash
# Termux换国内源
sed -i 's@packages.termux.org@mirrors.tuna.tsinghua.edu.cn/termux@g' $PREFIX/etc/apt/sources.list

# 安装OpenSSH
apt update
apt install openssh

# 启动SSH服务
sshd

# 安装PRoot-Distro
apt install proot-distro

# 列出可用发行版
proot-distro list

# 安装Ubuntu
proot-distro install ubuntu

# 登录Ubuntu
proot-distro login ubuntu
```

## 可复用的经验/最佳实践

1. **推荐下载版本**：termux-app_v0.118.3+github-debug_arm64-v8a.apk
2. **存储需求**：预留2-5GB空间
3. **内存需求**：8-16GB手机足够
4. **后台保护**：将Termux加入系统清理白名单
5. **长期使用优先F-Droid版本**：避免Debug版的覆盖安装问题
6. **充分利用移动性**：always-on特性，便携性强
