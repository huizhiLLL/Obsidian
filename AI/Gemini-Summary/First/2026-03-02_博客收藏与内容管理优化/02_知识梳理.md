# 博客收藏与内容管理优化 - 知识梳理

## 涉及的技术栈/工具

- **博客平台**：WordPress
- **笔记工具**：Obsidian
- **发布工具**：Obsidian WordPress插件
- **自定义文章类型**：CPT (Custom Post Type)
- **数据查询**：WP_Query、pre_get_posts钩子

## 关键概念与方法

- **收藏 vs 导航**：收藏但平时不访问的链接适合整理到文章，导航页面只放常用网站
- **CPT（自定义文章类型）**：独立于普通文章，不污染归档页面
- **WP_Query**：WordPress自定义查询接口
- **pre_get_posts钩子**：在主查询执行前修改查询参数
- **数据分离思路**：从数据库查询层面彻底解决分类问题
- **Obsidian侧自动化**：Dataview或Python脚本定期聚合

## 重要的代码片段或命令

```php
// functions.php 添加自定义文章类型
function register_resources_cpt() {
    register_post_type('resources', array(
        'labels' => array(
            'name' => '资源',
            'singular_name' => '资源'
        ),
        'public' => true,
        'has_archive' => false, // 不显示在归档页面
        'show_in_rest' => true,
        'supports' => array('title', 'editor', 'thumbnail')
    ));
}
add_action('init', 'register_resources_cpt');
```

```php
// 归档页面排除特定分类
function exclude_category_from_archive($query) {
    if ($query->is_archive() || $query->is_home()) {
        $query->set('cat', '-10'); // 排除分类ID 10
    }
}
add_action('pre_get_posts', 'exclude_category_from_archive');
```

```python
# Obsidian聚合脚本示例
import os
import shutil

source_folder = "Obsidian/links"
output_file = "wordpress-import.md"

# 聚合所有链接文件
with open(output_file, 'w', encoding='utf-8') as out:
    for root, dirs, files in os.walk(source_folder):
        for file in files:
            if file.endswith('.md'):
                with open(os.path.join(root, file), 'r', encoding='utf-8') as f:
                    out.write(f.read() + '\n\n')
```

## 解决方案对比

| 方案 | 技术深度 | 优点 | 缺点 |
|------|----------|------|------|
| CPT | 中 | 彻底解决，数据分离 | 需要代码/插件 |
| 标签过滤 | 低 | 简单易行 | 可能影响其他查询 |
| Obsidian聚合 | 中 | 减少WP文章数量 | 需要维护脚本 |
| 独立工具 | 高 | 完全解耦 | 需要额外部署 |

## 可复用的经验/最佳实践

1. **CPT是最佳方案**：独立于普通文章，不污染归档
2. **收藏与导航分离**：区分"Archive"和"Navigation"的本质
3. **pre_get_posts钩子**：灵活控制查询行为
4. **Obsidian侧聚合**：减少WordPress端维护工作量
5. **LinkStack/Heimdall**：作为独立导航服务解耦
6. **数据分离思路**：通用于产品展示、案例集等场景
