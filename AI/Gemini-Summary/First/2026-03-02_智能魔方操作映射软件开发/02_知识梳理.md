# 智能魔方操作映射软件开发 - 知识梳理

## 涉及的技术栈/工具

- **Python** - 后端核心逻辑
- **bleak** - 跨平台蓝牙库
- **asyncio** - 异步核心循环
- **pydirectinput** - 模拟键盘鼠标输入
- **Vue 3 + Vite** - 前端 UI
- **NiceGUI** - Python + Vue Web UI 框架
- **Tauri v2** - Rust + Web 技术桌面应用
- **Three.js** - 3D 渲染（可选）
- **Nuitka** - Python 打包工具

## 关键概念与方法

- **二次开发评估**: 基于开源项目进行功能增强和体验优化
- **前后端分离架构**: Python 后端 + NiceGUI/Vue 前端
- **配置驱动设计**: JSON/YAML 配置文件替代硬编码
- **模块化解耦**: 剥离蓝牙连接、协议解析、输入模拟为独立模块

- **技术选型原则**:
  - NiceGUI: 快速开发，数据传输便捷
  - Tauri v2: 性能更好，打包后体积小

## 可复用的经验/最佳实践

1. **消除硬编码**: 用配置文件管理按键映射，支持多预设切换
2. **保护源代码**: Nuitka 打包比 PyInstaller 性能更好
3. **3D 渲染替代 Matplotlib**: Vue + Three.js 性能更好，界面更现代
4. **用户体验设计**: 实时姿态显示 + 按键日志滚动，提升可玩性
5. **MVP 开发**: 先实现核心映射功能，再添加 UI 和高级功能
6. **硬件+软件+爱好结合**: 完美练手项目，整合多领域技能
